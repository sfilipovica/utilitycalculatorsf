# Komunālo maksājumu kalkulators

Šis projekts ir interaktīvs rīks elektrības un ūdens rēķinu aprēķināšanai, izmantojot JavaScript sliekšņu tarifu loģiku.

## Funkcionalitāte
- Datu ievade par patērēto elektrību (kWh) un ūdeni (m³).
- Aprēķins pēc divu līmeņu tarifiem.
- Ievades datu validācija.
- Dinamiska rezultātu parādīšana bez lapas pārlādes.

## Lietošanas instrukcija
1. Ievadiet patēriņa skaitļus attiecīgajos laukos.
2. Nospiediet pogu "Aprēķināt".
3. Rezultāta blokā redzēsiet kopējo summu un sadalījumu.
